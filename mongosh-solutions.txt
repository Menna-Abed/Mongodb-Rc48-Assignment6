Assignment 6 - MongoDB Shell Part
=================================


Q1/ Create an explicit books collection with validation.
-------------------------------------------------------

 db.createCollection("books", {
        validator: {
            $jsonSchema: {
                bsonType: "object",
                required: ["title"],
                properties: {
                    title: {
                        bsonType: "string",
                        minLength: 1,
                        description: "title must be a non-empty string"
                    }
                }
            }
        }
    });

Q10/Find all books published between 1990 and 2010.
----------------


db.books.find({
    year: {
        $gte: 1990,
        $lte: 2010
    }
});


====================================================================================================

Q11/Find books where genres includes Science Fiction.
----------------

});


====================================================================================================

Q12/Skip first two books, limit to next three, and sort by year descending.
----------------


db.books.find().sort({ year: -1 }).skip(2).limit(3);

Q13/Find books where year is stored as an integer.
----------------


db.books.find({

Q14/Find books where genres does not include Horror or Science Fiction.
----------------


db.books.find({
    genres: {
        $nin: ["Horror", "Science Fiction"]
    }
});


====================================================================================================

Q15/Delete all books published before 2000.

db.books.deleteMany({
    year: {
        $lt: 2000
    }
});


====================================================================================================

Q16/Using aggregation, filter books published after 2000 and sort them by year descending.
----------------


db.books.aggregate([
    { $match: { year: { $gt: 2000 } }  },
    { $sort: { year: -1 }  }
]);


====================================================================================================

Q17/Using aggregation, find books published after 2000 and show only title, author and year.
----------------


db.books.aggregate([
    { $match: { year: {  $gt: 2000 }  }  },
    {  $project: {  _id: 0,  title: 1,  author: 1, year: 1 } }
]);


====================================================================================================

Q18/Using aggregation, break genres array into separate documents.
-----------------------------------------------------------------


db.books.aggregate([
    { $unwind: "$genres" }
    { $project: { _id: 0, title: 1, genres: 1 } }
]);


====================================================================================================


Q19/Using aggregation, join books collection with logs collection.
----------------------------------------------------------


db.books.aggregate([
        { $addFields: {
                converted_book_id: {  $convert: {  input: "$book_id", to: "objectId"  }  }
                    } },
        {
            $lookup: {
                from: "books",
                localField: "converted_book_id",
                foreignField: "_id",
                as: "book_details"
            }
        },
        {
            $project: {
                _id: 0,
                action: 1,
                "book_details.title": 1,
                "book_details.author": 1,
                "book_details.year": 1
            }
        }

]);
